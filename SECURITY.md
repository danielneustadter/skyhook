# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](https://github.com/danielneustadter/skyhook/security/advisories/new)
rather than opening a public issue.

You can expect an acknowledgment within 72 hours.

## Scope

This is a demonstration project. The service is not deployed anywhere and holds no
real data, but pipeline and configuration findings (workflow injection, permission
escalation, scanner bypasses, container/K8s hardening gaps) are genuinely welcome —
the pipeline *is* the product here.

## Supported versions

Only the `main` branch is supported.
